# 臺灣 108 課綱國小數學迷思概念雲端資料庫系統

本專案為一個純前端單頁面應用程式 (Serverless SPA)，整合 Google Gemini API (Vision 多模態影像辨識) 與 Supabase 雲端資料庫，旨在協助國小教師透過 AI 即時診斷學生的數學計算錯誤，自動將其分類至對應的 108 課綱學習內容與預設的「數學迷思概念樣態」，並建立班級的學習弱點大數據分析儀表板。

---

## 🌟 核心特色
1. **Gemini 多模態診斷**：支援拍照上傳學生手寫計算算式，AI 自動進行 OCR 並逐步推理診斷。
2. **對齊 108 課綱**：內建國小一至六年級數學指標（包含數與量 N、空間形狀 S、關係 R、資料不確定性 D）及數十種常見迷思樣態。
3. **雲端與離線雙存取**：整合 Supabase 雲端資料庫儲存紀錄；在斷網時自動轉為本機 `localStorage` 儲存，並支援一鍵同步。
4. **教師分析儀表板**：
   - SVG 動態繪製「高頻迷思排行榜」。
   - 年級 x 領域 犯錯次數熱力圖。
   - 學生個人「弱點診斷報告與補救教學建議卡」產出及 A4 列印優化。
5. **學生自主學習入口 (student.html)**：
   - 學生專屬錯題本：輸入姓名與年級，即可自動讀取個人的歷史答錯小卡。
   - AI 挑戰擂台：針對曾犯錯的迷思樣態，AI 動態生成同類型新題目，並依據學生輸入的解題過程進行智能批改與鼓勵。
6. **資料庫匯入/匯出**：完整支援將歷程紀錄匯出為 `.json` 檔案及從備份檔案復原。

---

## 📂 專案檔案結構
- `index.html`：整合學生診斷、教師後台、歷程列表及金鑰設定的單頁面架構。
- `style.css`：質感深/淺雙色自適應 Vanilla CSS 樣式、動態過渡動畫與列印樣式優化。
- `data.js`：臺灣 108 課綱國小數學指標與預設迷思樣態資料集。
- `db.js`：Supabase 雲端資料庫連線、本地 LocalStorage 備份與離線批次同步邏輯。
- `app.js`：UI 控制、SVG/Heatmap 渲染、Gemini API 串接與錯誤流程處理。
- `setup.sql`：Supabase 資料表結構與 Row Level Security (RLS) 權限指令。

## 🚀 快速啟動指南

### 第一步：設定雲端資料庫 (Supabase)
1. 註冊/登入 [Supabase 官網](https://supabase.com/)。
2. 建立一個新專案 (Project)。
3. 在專案左側導覽點擊 **SQL Editor**，點擊 **New query**。
4. 將專案中的 `setup.sql` 內容貼入編輯器中，點擊 **Run** 執行。這將會建立 `misconception_records` 資料表。

### 第二步：執行本系統
本專案為**純前端靜態網頁**，您不需要配置 Node.js 伺服器，可以使用以下兩種方式之一運行：
1. **直接開啟**：在檔案總管中雙擊 `index.html`，即可直接於瀏覽器中開啟使用。
2. **使用本地伺服器 (推薦)**：在專案目錄下執行 Python 簡易伺服器：
   ```bash
   python -m http-server 8000
   ```
   或使用 Node.js 的 `live-server` 或 `http-server` 執行，並在瀏覽器輸入 `http://localhost:8000`。

### 第三步：金鑰與連線設定
1. 在網頁左側選單點選 **「系統與雲端設定」**。
2. **Gemini 設定**：填入您的 Google Gemini API Key，並選擇欲使用的模型（預設為推薦的 `gemini-1.5-flash`）。
3. **Supabase 設定**：
   - 填入您的 **Project URL**（可在 Supabase 的 Project Settings -> API 中找到）。
   - 填入您的 **Anon Key**（可在同一頁面找到）。
   - 設定 **Teacher ID**（預設為 `admin`，用以區分您的班級資料）。
4. 點選 **「測試資料庫連線」**，若彈出連線成功通知即完成設定！

## 📝 臺灣 108 課綱內建迷思概念範例
系統中已預設整理多項經典概念：
- **分數加減法**：分母與分母相加，分子與分子相加（如 $1/2 + 1/3 = 2/5$，課綱 N-5-4）。
- **直式減法**：退位忘記扣一、不夠減時顛倒用大數減小數（課綱 N-2-2）。
- **除法直式**：商中間不夠除漏寫 0（如 $816 \div 8 = 12$，課綱 N-3-4）、餘數大於除數等。
- **混合運算**：未遵循先乘除後加減、忽略括號優先權（課綱 N-4-4）。
- **分數除法**：除以分數忘記倒數相乘（課綱 N-6-1）。
